## Краткое описание

**Portfolio** — персональный сайт-портфолио Frontend-разработчика на Next.js 15 (App Router).

Основные возможности:
- Главная страница с секциями: приветствие, технологии, работы, контакты.
- Каталог проектов (работ), подгружаемый из PostgreSQL через Prisma.
- Страница детального просмотра проекта `/projects/[id]` с описанием, функциями и стеком.
- SEO-метаданные для страниц проектов (`generateMetadata`).
