# Обзор проекта

## Что это

**Portfolio** — персональный сайт-портфолио Frontend-разработчика (Руслан). Next.js 15 (App Router) + PostgreSQL (Neon) + Prisma + Tailwind CSS.

## Возможности

- **Главная страница** (`/`):
  - Секция-приветствие с аватаром и описанием.
  - Секция «Технологии» — сетка иконок (HTML, CSS, SCSS, JS, Alpine, React, Redux, Zustand, Git, Postman, VS Code, GitHub).
  - Секция «Работы» — карточки проектов из БД.
  - Секция «Контакты» — Telegram, телефон, Viber.
- **Страница проекта** (`/projects/[id]`):
  - Название, скриншот, описание, функции, стек.
  - SEO-метаданные через `generateMetadata`.
  - 404 при отсутствии проекта (`notFound()`).

## Страницы и маршруты

| Маршрут | Тип | Рендеринг |
|---------|-----|-----------|
| `/` | Server Component | SSR, данные из Prisma |
| `/projects/[id]` | Server Component | SSR, динамический сегмент |

## Модель данных

Единственная сущность — **Product** (проект портфолио): название, ссылка, скриншот, описание, стек, функции.

## Технические особенности

- **Server Components** — запросы к БД выполняются на сервере, данные приходят в HTML.
- **Динамические метаданные** — `generateMetadata` для страниц проектов.
- **Prisma Singleton** — защита от лишних подключений в dev.
- **HTML-контент из БД** — описания проектов рендерятся через `dangerouslySetInnerHTML`.

## Известные ограничения

1. Хардкод контактных данных в `app/page.tsx`.
2. `console.log` в продакшн-коде главной страницы.
3. Слой `services/` не подключён (нет API-роутов).
4. Статический API-ключ в `services/instance.ts`.
5. Используются `<img>` вместо `next/image`.
6. Метаданные layout: `title: "Create Next App"` — шаблонные, не персонализированы.
