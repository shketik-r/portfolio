# Добавление нового проекта

Инструкция по добавлению проекта в портфолио.

## Кратко

1. Положить скриншот в `public/screens/`.
2. Добавить объект в массив `products` в `prisma/consts.ts`.
3. Запустить `npm run prisma:seed`.
4. Проверить главную и страницу `/projects/[id]`.

## Подробно

### 1. Скриншот проекта

Помести файл в `public/screens/`, например `public/screens/myproject.png`.

Требования к изображению:

- формат: `png` (предпочтительно), допустимы `jpg`/`webp`;
- ширина: ~800–1600 px;
- соотношение сторон: горизонтальное, ~4:3 или 16:9;
- имя файла: латиница, без пробелов (например `minskcitymall.png`).

> ⚠️ Если файла нет, карточка и страница проекта покажут битую картинку.

### 2. Запись в сидах

Открой `prisma/consts.ts` и добавь объект в массив `products`:

```ts
export const products = [
  // ...существующие проекты
  {
    name: 'example.com',
    imageUrl: './screens/example.png',
    linkSite: 'https://example.com/',
    desc: '<p> Краткое описание проекта. </p> <ul><li>Пункт 1</li><li>Пункт 2</li></ul>',
    stack: 'HTML, CSS, JS, Alpine.js, Laravel',
    functions: '<ul><li>Функция 1</li><li>Функция 2</li></ul>',
  },
];
```

#### Поля

| Поле | Тип | Описание |
|------|-----|----------|
| `name` | `string` | Название проекта (домен или имя) |
| `imageUrl` | `string` | Путь к скриншоту относительно `public/`, начинается с `./screens/` |
| `linkSite` | `string` | Полный URL сайта, включая `https://` |
| `desc` | `string` | HTML-описание проекта (`<p>`, `<ul>`, `<li>`) |
| `stack` | `string` | Технологии через запятую |
| `functions` | `string` | HTML-список основных функций сайта |

#### Правила заполнения

- **`imageUrl`** — всегда `./screens/<файл>` (без ведущего слэша и без `public/`).
- **`desc`** — начинается с `<p>` с описанием назначения сайта, затем `<ul>` с ключевыми направлениями.
- **`functions`** — `<ul>` со списком `<li>`, каждый пункт — конкретная возможность сайта.
- **`stack`** — перечисляй реальные технологии проекта через запятую, без лишних пробелов внутри названий.
- Экранируй кавычки внутри HTML-строк, если они есть.

### 3. Применение в БД

Сид сначала очищает таблицу, затем создаёт все записи заново:

```bash
npm run prisma:seed
```

> ⚠️ Команда выполняет `TRUNCATE TABLE "Product" RESTART IDENTITY CASCADE` — все текущие записи удаляются и пересоздаются из `consts.ts`. Убедись, что все проекты есть в массиве `products`.

### 4. Проверка

- Главная (`/`) — новая карточка в секции «Работы».
- Страница проекта (`/projects/<id>`) — описание, функции, стек, скриншот.
- Метаданные вкладки — название проекта.

## Чек-лист

- [ ] `linkSite` открывается
- [ ] Запущен `npm run prisma:seed`
- [ ] Проверены главная и `/projects/[id]`
